A fast, modern file manager for storage you already own.

9Drive is self-hosted software that puts a clean web and Android interface in front of your own Google Drive or S3 bucket. Upload, organise, share and restore your files without handing them to yet another cloud provider.

Get 9Drive on GitHub

Your storage, your rules

Files live in your Google Drive or S3 account. 9Drive stores metadata and proxies transfers — nothing else.

Folders, search and trash

Nested folders, grid and list views, fast search, soft-delete with a Trash view, and starred files.

Sharing and API keys

Create public links deliberately, and issue scoped API keys for scripted uploads.

Android app

A Capacitor build of the same interface, so your server is one tap away on your phone.
