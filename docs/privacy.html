Privacy policy

Last updated: 13 November 2026

9Drive is self-hosted, open-source file management software (Apache License 2.0). This policy describes the 9Drive instance operated by the project maintainer, and explains what the server stores, what it accesses from Google, and how you stay in control. It is written to satisfy the Google API Services User Data Policy for the Google Drive integration.

1. What the server stores

  • Your email address and a salted password hash — never your password itself.
  • Session and refresh tokens that keep you signed in.
  • Google OAuth access and refresh tokens, encrypted at rest with AES-256-GCM using a key held only by the operator.
  • File and folder metadata: name, size, MIME type, checksum, the Drive file identifier, and timestamps.
  • An audit log of actions you perform in the app (uploads, downloads, deletes, sign-ins).

File contents are not stored on the 9Drive server. Files are written to the storage account you connect — normally your own Google Drive — and the server only proxies them while you use the app.

2. Google user data 9Drive accesses

When you connect a Google account, 9Drive requests only these scopes:

ScopeWhy it is required
auth/drive Create, read, update, move and delete the files and folders you manage through 9Drive, and read your storage quota.
auth/userinfo.email Show which Google account is connected and tie it to your 9Drive login.
auth/userinfo.profile Display your name and avatar inside the app.

9Drive does not request access to Gmail, Calendar, Contacts, or any other Google service.

3. How Google user data is used

Information obtained from Google APIs is used solely to provide the features you explicitly trigger in the app: listing, uploading, downloading, previewing, renaming, moving, sharing and deleting files, and reporting storage usage.

9Drive does not sell Google user data, does not use it for advertising, does not use it to build user profiles, and does not use it to develop, improve or train generalised machine-learning models. It is not transferred to third parties except the infrastructure required to run the server (section 5).

Limited Use disclosure. 9Drive's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. Your control over the data

You connect a Google account by granting OAuth consent, and you can withdraw it at any time:

  • Revoke 9Drive's access at myaccount.google.com/permissions.
  • Disconnect the account inside 9Drive (Settings → Connected accounts), which deletes the stored tokens.
  • Delete your 9Drive account, which removes your account record, stored tokens and file metadata.

Revoking access stops all further Drive operations immediately. Files already in your Google Drive remain yours and are unaffected.

5. Where data lives and who can see it

The server runs on infrastructure chosen by the instance operator. OAuth tokens are encrypted at rest; traffic between the app and the server is protected by HTTPS. Data is not shared with third parties, except where the operator relies on a hosting provider to run the server, or where disclosure is required by law.

6. Retention

Account data, tokens and file metadata are kept until you delete them or delete your account. Deleted files move to the app's Trash and are removed permanently when you empty it. Operational server logs are retained briefly for security and troubleshooting.

7. Children

9Drive is not directed at children under 13, and the operator does not knowingly collect their data.

8. Changes to this policy

Material changes will be published on this page together with a new "last updated" date.

9. Contact
